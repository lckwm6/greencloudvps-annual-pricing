## 年付之前，先算三笔账

年付 VPS 的真实成本由三件事决定：首期价、续费价、计费周期。多数促销文章只讲第一件事。

第一笔是续费。2026 年一份覆盖 391 家 VPS 商家的统计显示，入门价中位数是首年 $9.95/月、续费 $11.46/月；在公布续费价的 52 家里，只有 19 家续费不涨价。极端案例像 BuyVPS 的 S-2 套餐，从 $1/月涨到续费 $7.99/月。Hostinger 更典型：入门 KVM 1 套餐首期 $6.49/月，续费 $11.99/月，涨幅 85%。所以看到“超低价年付”时，第一个要确认的就是续费同不同价。

第二笔是合约首期价的伪装。IONOS 的 VPS S+ 标价 $2/月，但那是 1 年合约、前 3 个月的折扣价，之后恢复 $6/月原价；GoDaddy 的 £7.49/月也是 3 年合约首期价。这类大厂的价格结构是“先低价锁定合约，到期自动按原价续费”，和预算商家的“真年付低价”完全不是一回事。如果你一年后大概率不续，这种结构未必省钱。

第三笔是年付本身相对月付的折让。预算商家在这一项上通常给得很大方，比如 DediRock 的年付月均成本比月付低 50–70%，GreenCloudVPS 也有套餐从 $10/月降到年付折合 $2.92/月的记录。能接受年付，这个差价没有理由放弃。
